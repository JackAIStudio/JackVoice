关于

JackVoice · v0.1.0
开源全局语音听写器：按快捷键说话，识别结果自动插入当前焦点或剪贴板。
识别核心：火山引擎豆包流式语音识别模型 2.0（Seed-ASR 2.0，双向流式优化版 + 二遍识别），支持自定义词库。
源代码采用 Apache-2.0 许可证；语音会发送至用户自行配置的火山引擎服务。
JackVoice

欢迎使用 JackVoice

全局语音听写：按一下快捷键开始说话，说完再按一下，识别结果会自动插入你正在输入的地方。

正式开始前，请先花一分钟完成权限、数据保存方式和识别服务配置。

麦克风权限

听写需要麦克风采集你的声音。点击下方「测试麦克风」，系统会弹出授权窗口，请选择「允许」。

辅助功能权限

听写结束后，JackVoice 会把文字自动插入你当前使用的应用（相当于帮你按一下粘贴）。这一步需要「辅助功能」权限。

点击下方按钮，在系统设置里找到 JackVoice 并打开开关，然后回到这里点「我已开启」。

数据与隐私

听写时，麦克风音频会通过加密连接实时发送至你自行配置的火山引擎账号进行识别。

转写文本保存在本机。录音默认保留 30 天，你可以改为不保存、保存 7 天或永久保存。

本地录音保留
到期只删除 WAV，转写文本仍可在首页手动删除。

请先确认你已了解数据处理方式。

可选设置

以下两项随时可以在「设置」里修改，可以稍后再填。

开机时启动应用
登录系统后自动在后台运行 JackVoice。
豆包录音识别 API Key

也可以点击主界面上的「开始听写」按钮。
